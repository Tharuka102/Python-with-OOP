# Python-with-OOP 🐍

This repository contains Python Object-Oriented Programming (OOP) concepts, examples, and small projects for learning and practice purposes.

---

## 📌 About the Project

This project is designed to help understand the core principles of **Object-Oriented Programming in Python**, including:

- Classes and Objects
- Constructors (`__init__`)
- Inheritance
- Polymorphism
- Encapsulation
- Abstraction

- Clean OOP structure
- Beginner-friendly examples
- Real-world mini projects
- Organized folder structure (like professional projects)
